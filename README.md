<h2>🛠 Installation</h2>

<p>1. Clone project</p>

```
git clone https://github.com/sherzodartikbayev/seleor.git
```
<p>2. Setup .env file to /client</p>

```
NEXT_PUBLIC_JWT_SECRET=
NEXT_AUTH_SECRET=
NEXTAUTH_URL=
NEXT_PUBLIC_SERVER_URL=
UPLOADTHING_TOKEN=
UPLOADTHING_SECRET=
```

<p>3. Frontend</p>

```
cd client && npm install && npm run dev
```

<p>4. Setup .env file to /server</p>

```
PORT=
CLIENT_URL=

MONGO_URI=

JWT_SECRET=

SMTP_PASSWORD=
SMTP_USER=
SMTP_PORT=
SMTP_HOST=

STRIPE_SECRET_KEY=

CLICK_SECRET_KEY=
CLICK_SERVICE_ID=
CLICK_MERCHANT_ID=
CLICK_MERCHANT_USER_ID=

PAYME_MERCHANT_ID=
PAYME_CHECKOUT_LINK=

UZUM_USERNAME=
UZUM_PASSWORD=
UZUM_SERVICE_ID=
```

<p>5. Backend</p>

```
cd server && npm install && npm run dev
```
